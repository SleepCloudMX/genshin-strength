橙虚线 = 10 / 20 / 30 / 40 词条的等词条线，与最优分配线的交点即该词条数下的最优拆分（标出该点的倍数）。悬浮出卡片与双箭头（黑 = 最优分配、钢蓝 = 梯度）；点击固定该点并显示标注（点别处即移动）。改下面任意一项，全图即时重算。
基准面板 = 上完 buff、不含副词条 —— 副词条正是这里要分配的东西。
双暴分
—
点图上任意位置，固定一个点。
图上：颜色 = 倍数；灰 = 配不出（只有「超过 43 词条」一种，卡片会红字说明）；细点线 = 1:2 配平可达下界，以下能配但配不平（基准的偏斜还没补完）；橙色实线 = 最优分配线（每个词条数 n 的最优位置；线上「词条重要性」恰为 0.50 · 0.50；与「最优分配」页的最优路径一致）；橙色虚线 = 等词条线（10 / 20 / 30 / 40 词条的预算线；右上遮罩边的灰虚线是 43 词条上限），与橙色实线的交点 = 该词条数下的精确最优拆分，交点标出该点的倍数（相较 0 词条）。
数值：倍数 = 该点伤害 ÷ 基准面板（上完 buff、不含副词条）的伤害，基准点 ×1.00；卡片与固定框里的另一个是固定参照「589 精通、5% 暴击、50% 暴伤、增伤 0%」之比，跨配置可比。每点都假设双暴已按约束最优配平；1 词条 = 20 精通 = 3.3% 暴击 = 6.6% 暴伤。
操作：悬浮即出卡片与双箭头（卡片自动避开右上——箭头只在右上，不会遮挡）；点击固定该点，chip 两行 —— 归一化梯度（钢蓝，即卡片里的「词条重要性」）与最优的分配（黑）。黑（主） = 「下一词条」的最优分配方向（只拆新的一条：α·20 精通 + (1−α)·6.6 双暴，已有词条不动；α 使落点命中最优分配线，够不到则整条给更值的一侧）；钢蓝（次） = 梯度方向（画面空间每像素增益最大，⊥ 等高线）。两箭头都按两轴刻度映射、长度固定、只指示方向。
轴的范围 = 基准 → 上限（+420 精通 / +43 词条）。算的是星扩散直伤（瑞希天赋「廓然梦生」的精通倍率伤害），不是反应星扩散。
