把 n 个等效词条分给精通 / 双暴 / 攻击：图上每个点是一套分配（攻击吃剩余），颜色 = 相对基准面板的伤害倍数，叠加倍数等高线；鼠标在图上时，箭头指向该点上升最快的方向（画面空间每像素增益最大）。滑条松开、数字框失焦 / 回车后才重算；武器横评见武器对比页。
基准面板 = 上完 buff、不含副词条（木偶 + 武器 + 攻攻暴主词条 + 羽 + 队友都算在里面）；不含套装特效 —— 幻灭 4 件的 +40% 增伤与条件 +16% 暴击（按全覆盖）由脚本自动加。
词条口径：1 词条 = 20 精通 = 3.3% 暴击 = 6.6% 暴伤 = 5% 大攻击（小攻击见换算行）。攻击词条按大攻击折算 —— 当前基础攻击力下大攻击每词条恒优于小攻击；双暴按 1 : 2 配平（先补基准的偏斜）。
