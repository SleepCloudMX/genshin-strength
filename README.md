# 原神强度计算

以**梦见月瑞希的星扩散直伤**为例的伤害计算与可视化。

目前只有这一个角色、两个需求。做满几个需求之后再看要不要重新组织。

## 结论速览

**血红之证 4 件套 vs 精通 2+2**（[`tasks/mizuki/scarlet_vs_em22.py`](tasks/mizuki/scarlet_vs_em22.py)）

分界线在 **940 ~ 1200 精通**之间，随双暴词条数下降 —— 精通低于它选 2+2，高于它选血红。瑞希实际就压在这条线上，两套差距 **6% 以内**，配装时基本不用纠结。

**精通与双暴的最优分配**（[`tasks/mizuki/em_vs_crit.py`](tasks/mizuki/em_vs_crit.py)）

最优解存在但**不敏感**：`n` 个等效词条里给双暴 `b* ≈ 0.4 ~ 0.73 n`，但 `n = 25` 时双暴落在 9.4 ~ 23.0 词条之间都在最优的 99% 以内。峰值只比「词条全给精通」高 5.6%（`n = 25`）、12.6%（`n = 35`）。**两个方向的代价不对称** —— 全给双暴只亏 1.6% ~ 2.6%，而全给精通亏 5.3% ~ 11.2%。

配比规则：基础面板暴击率偏低，所以**双暴词条先补暴击率**直到 `暴击 : 暴伤 ≈ 1 : 2`（约 6 个词条），之后按 1:2 同步加。

## 术语

**等效词条** —— 圣遗物副词条的平均成长值。`1 词条 = 20 精通 = 3.3% 暴击 = 6.6% 暴伤`。

> ⚠️ 只适用于**副词条**。主词条、武器、天赋、队友给的量不能换算 —— 1 词条的主词条精通是 187，主词条暴击是 31.1%，两者并不等价（各自四舍五入过）。

**双暴分** —— `暴击率 + 暴伤 / 2`。理之冠的暴击/暴伤主词条可以自由选取，两种冠给出的双暴分完全相同，所以描述基准面板时用它这个不变量，而不是「36% 暴击 / 112.2% 暴伤」。

**基准面板** —— **上完 buff、不含圣遗物副词条**的部分。只有副词条参与词条分配，其余都算在基准里。

## 运行

需要 Python ≥ 3.11。

```bash
pip install -e .          # 装 numpy / scipy / matplotlib，并让脚本能 import genshin_strength
```

两个脚本，产物都写到 `output/`：

```bash
python tasks/mizuki/scarlet_vs_em22.py    # 血红 vs 精通 2+2，两张比值热力图
python tasks/mizuki/em_vs_crit.py         # 精通 vs 双暴最优分配，两张曲线图
```

另有两个**可交互页面**，它们不是生成的，就是那两个文件本身，**双击直接用浏览器打开**（Plotly 走 CDN，需要联网）：

| 页面 | 做什么 |
| --- | --- |
| [`tasks/mizuki/scarlet_vs_em22.html`](tasks/mizuki/scarlet_vs_em22.html) | 血红 vs 精通 2+2 的比值热力图。**它同时就是计算器** —— 填「星扩散增伤 / 基准精通 / 双暴分」，图上十字准星定位并给出比值、谁更优、以及精通到多少才翻面 |
| [`tasks/mizuki/em_vs_crit.html`](tasks/mizuki/em_vs_crit.html) | 精通 vs 双暴的最优分配。悬浮曲线读该点的双暴拆分、精通、伤害倍数；基准面板、星扩散增伤、曲线取哪几个 `n`、平台阈值都可改 |

也通过 GitHub Pages 提供在线版，链接形如

## 目录

```
genshin_strength/               共享层：星扩散的公式常数与暴击区
tasks/<角色>/<需求>.py           每个需求一个脚本：本任务的数据 + 这张图的画法
tasks/mizuki/*.html             可交互页面（自包含，双击直接打开）
output/<角色>/<任务>/            产物，gitignore
```

`genshin_strength/` 现在只有一个模块。它存在的理由不是复用，是**唯一真源** —— 星扩散的精通系数是 `6` 而不是传统剧变反应的 `16`，这类常数错一次不会报错、只会静默算错。

## 注意

- 算的是**星扩散直伤**（瑞希天赋「廓然梦生」的「元素精通 1000%」倍率伤害），**不是反应星扩散**（占比很小）。公式里没有 `1446.85`，属性是元素精通而非攻击力。
- 暴击区取**期望值** `1 + 暴击率 × 暴伤`。单次伤害是二值的，瑞希一次循环里伤害次数不多，实战体感与期望可能有出入。
- 部分游戏机制来自社区与解包数据，**非官方文本**。存疑处在文档里逐条标注了。
- **可交互页面里的数学是 JS 重写的一份**（浏览器要实时重算，绕不开）。改公式时 `tasks/mizuki/em_vs_crit.py` 与 `em_vs_crit.html` 里的 JS **必须同时改**，两边都有注释指认对方。
