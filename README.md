# 原神强度计算

原神伤害计算与可视化。把伤害公式拆成乘区，用交互图表看「面板 → 词条分配 → 伤害」的走向：给定角色、武器、队友与战斗条件，图上显示伤害随精通 / 双暴 / 攻击 / 防御的分配怎么变、最优分配在哪、套装与武器之间差多少。

站点是静态网页：一个入口、左侧目录切换，打开即用，不需要构建或后台。

## 入口

在线：[sleepcloudmx.github.io/genshin-strength](https://sleepcloudmx.github.io/genshin-strength/)

本地：下载仓库后双击根目录的 `index.html`（Plotly / KaTeX 走 CDN，需要联网）。旧地址 `tasks/…` 会跳转到对应页面。

## 内容

- **梦见月瑞希**：星扩散的套装对比、精通 × 双暴的词条分配与伤害热图；星扩散机制说明（开头带计算器）。
- **桑多涅**：星超导的词条分配、伤害热图、武器对比。
- **米提亚**：星超导的套装对比、词条分配、伤害热图、武器对比。
- **千织**：岩伤「袖」斩切的词条分配、伤害热图、武器对比。
- **基础专题**：抗性区（减抗收益 / 等效血量）、暴击的波动与按分位数分配。

每页右侧参数都可改；图上悬浮读数、点击固定所选点；参数「明细」可展开每个数值的逐项来源。

## 口径

- **等效词条**：副词条四档成长值的均值，统一在 `web/js/core/const.js` 的 `C.ROLL` 表定义（精通 19.815 / 暴击 3.305% / 暴伤 6.605% / 大攻击 4.955% …）。
- **基准面板**：上完 buff、不含圣遗物副词条；只有副词条参与词条分配。
- **暴击区**：取期望 `1 + 暴击率 × 暴伤`；暴击率上限 100%。
- 各角色的公式、乘区来源与待核实点见 `docs/ai-output/0-mechanism/`；页面结论直接以页面读数与机制文档为准。

## 仓库结构

- `index.html` + `web/`：站点。`web/js/core/` 是全部公式的唯一真源（纯函数，Node 可直接加载）；`web/js/modules/` 每页一个模块；`web/js/ui/` 是图表、悬浮卡、叠加层与控件。
- `docs/ai-output/`：机制考证、需求结论、经验与逐日日志（独立 git 仓库）；`docs/ai-ref/`：原始资料（独立仓库）。
- `tasks/`：旧地址跳转桩与早期 Python 脚本；`output/`：脚本产物（gitignored）。

## 运行与验证

无构建步骤，改完刷新即可。数值可用 Node 直接加载 `web/js/core/*.js` 复算；无头 Chrome 用于页面探针与截图（项目约定见 `docs/ai-output/memory.md`）。
