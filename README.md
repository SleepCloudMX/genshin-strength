## 结论速览

**血红之证 4 件套 vs 精通套**（[在线算一算](https://sleepcloudmx.github.io/genshin-strength/#/mizuki/scarlet_vs_em)）

分界线在 **约 850 ~ 1220 精通**之间（随双暴词条数与所选精通套变化）—— 精通低于它选精通套，高于它选血红。瑞希实际就压在这条线附近，差距都在百分之几，配装时基本不用纠结。

**但精通套本身的选择也会翻面**：饰金之梦 4 件套（队友两种异元素 → +180 精通）比精通 2+2（+160）只多 20 精通 —— 默认面板（1000 精通、双暴分 240）与饰金几乎持平（血红 / 饰金 = 1.0036），换成 2+2 则是血红高 2.5%。

**精通与双暴的最优分配**（[在线算一算](https://sleepcloudmx.github.io/genshin-strength/#/mizuki/em_vs_crit)）

最优解存在但**不敏感**：`n` 个等效词条里给双暴 `b* ≈ 0.86 ~ 0.89 n`，但 `n = 25` 时双暴落在 15.5 ~ 25.0 词条之间都在最优的 99% 以内。峰值只比「词条全给精通」高 9.7%（`n = 25`）、17.9%（`n = 35`）。**两个方向的代价不对称** —— 全给双暴只亏 0.1% ~ 0.7%，而全给精通亏 8.8% ~ 15.2%。（以上为页面默认口径，星扩散直伤占比 90%。）

配比规则：基础面板暴击率偏低，所以**双暴词条先补暴击率**直到 `暴击 : 暴伤 ≈ 1 : 2`（约 6 个词条），之后按 1:2 同步加。

**抗性区：减抗收益**（[在线算一算](https://sleepcloudmx.github.io/genshin-strength/#/basics/resistance)）

固定削减 `S` 的收益峰值 = **`1 + 4S`**，出现在 75% 抗性的敌人身上（削减大到能削穿时，则出现在恰好被削到 0 的敌人身上）；抗性再高，收益反而**回落** —— 同为 40% 削减，90% 敌人 ×2.30、200% 敌人只有 ×1.22。100% 抗性仍打出 **20%** 伤害，公式压不到 0。减抗的另一面是**等效血量**：同一减抗下把高抗敌人往 10% 抗性敌人（多数敌人）的厚度上压 —— 120% 敌人不减抗相当于 ×5.22，带 40% 削减后 ×4.83。

**暴击：波动与分配**（[波动](https://sleepcloudmx.github.io/genshin-strength/#/basics/crit_dist) / [分配](https://sleepcloudmx.github.io/genshin-strength/#/basics/crit_split)）

未满暴时反复打，DPS 会波动 —— 分布是**有限支撑**的，可以精确算：`μ ± 3σ` 常常落在伤害上限之外，别用正态近似。「打 7 次取最好」≈ 看**前 9.4%** 的分位。双暴分固定时，**1 : 2 只是「均值口径」的最优**：按前 10% 可达伤害优化，暴击率会往下让一截（示例 n = 25：**66 / 188**），前 10% 伤害 +4.0%、均值只让 1.7%；想稳（看兜底）则相反，极端直接贴满暴。

**桑多涅星超导的词条分配**（[词条分配](https://sleepcloudmx.github.io/genshin-strength/#/sandrone/alloc_curve) / [伤害热图](https://sleepcloudmx.github.io/genshin-strength/#/sandrone/star_superconduct) / [武器对比](https://sleepcloudmx.github.io/genshin-strength/#/sandrone/weapon_compare)）

默认参数（七七 · 木偶 · 阿罗夏 队）30 词条下最优 = **双暴吃满（精通 0 · 双暴 30 · 攻击 0）** —— 160 基准精通（固有天赋 2）与 160% 反应增伤把精通项稀释到位，副词条再堆精通 / 攻击都不如双暴（「大 / 小攻击」折算成同一根轴：1 大攻击词条 = 基础攻击 × 5%，1 小攻击 = 16.5，828 基线下约 2.5 : 1）。

「词条分配」页给出这条结论的全景：词条先喂双暴 —— 约 27 条时暴击率封顶 100%、之后全进暴伤；约 41 条起精通才开始分走少量词条（到 53 条为精通 ≈ 239）；攻击词条在 53 条预算内**始终未进入最优**（离门槛只差约 0.008 个百分点 / 条）。

**千织「袖」斩切的词条分配**（[词条分配](https://sleepcloudmx.github.io/genshin-strength/#/chiori/alloc_curve) / [伤害热图](https://sleepcloudmx.github.io/genshin-strength/#/chiori/dmg_map) / [武器对比](https://sleepcloudmx.github.io/genshin-strength/#/chiori/weapon_compare)）

## 术语

**等效词条** —— 圣遗物副词条四档成长值的均值（米游社数据）。`1 词条 = 19.815 精通 = 3.305% 暴击 = 6.605% 暴伤`（大攻击 4.955% / 小攻击 16.535 / 大防御 6.195% / 小防御 19.675）；统一在 `web/js/core/const.js` 的 `C.ROLL` 表定义。

> ⚠️ 只适用于**副词条**。主词条、武器、天赋、队友给的量不能换算 —— 1 词条的主词条精通是 187，主词条暴击是 31.1%，两者并不等价（各自四舍五入过）。

**双暴分** —— `2 × 暴击率 + 暴伤`（等效暴伤，即常见口径的双暴分）。理之冠的暴击/暴伤主词条可以自由选取，两种冠给出的双暴分完全相同，所以描述基准面板时用它这个不变量，而不是「36% 暴击 / 112.2% 暴伤」。

**基准面板** —— **上完 buff、不含圣遗物副词条**的部分。只有副词条参与词条分配，其余都算在基准里。

## 说明

- 算的是**星扩散直伤**（瑞希天赋「廓然梦生」的「元素精通 1000%」倍率伤害），**不是反应星扩散**（后者占比很小）。属性是元素精通，不是攻击力。三个页面都有「星扩散直伤占比」滑条（默认 90%），可按**给定比例**把反应一并计入 —— 占比经游戏内实测约九成；瑞希 80 → 90 级单人提升 3.6%、全队约 2%。
- 桑多涅三页算**星超导**（伤害吃攻击力 / 精通 / 双暴，公式见机制页）；武器对比页的武器特效只计对星超导生效的常驻部分（按全覆盖 / 满层假设）。
- 千织三页算**「袖」斩切**（元素战技伤害，10 级、0 命口径）：三个部件的防御系数 = 1.25 × 攻击系数，只看斩切即可代表整体。伤害热图页的伤害数字**计入右侧「敌人区」参数**（默认角色 80 级、敌人 110 级、敌人抗性 10%、减防 / 无视防御 0 → 防御系数 0.4615、岩抗系数 0.90），即对当前参数敌人的最终伤害；参数在面板底部折叠组里可调，图上颜色与倍率为相对值、不受影响，悬浮数字可见完整计算过程。
- 米提亚页算**单段星超导**（10 级「递变聚爆」每消耗 1 枚信标的 403.2% 元素精通部分），攻击力不参与；星超导无防御区，抗性按雷抗分段。默认武器秘星典谕 R1（+120 精通、+148.2% 暴伤）。默认 2 命过载态：C1 +40% 暴伤、C2 +234 精通 / 敌人冰雷抗 −20%；A4 +20% 暴击率、A6 按精通 +14% 星超导基础伤害计入基准；默认主词条精精暴（暴击头）。**绘图范围固定 0–47 词条**（细线 5 / 10 / … / 45，橙线 = 当前预算）；预算只决定最优分配，不是绘图上限。双暴分配**只加不减**：不要求 1:2 可配平，不画「配平不可达」线，按实际可达的最优算。
- 米提亚武器对比页以**秘星典谕 R1 = 100**：公共面板 = 幻灭 4 + 精通沙 / 精通杯（不含头），每把武器在暴击头 / 精通头之间按自身最优分配取高者、行内标出差距；流浪乐章分「三选一期望」与「命中精通曲上限」两行；寝正月初晴只计战技 + 爆发精通（米提亚不能触发扩散）。
- 面板里每个数值都可以**直接改总数**，或点「明细」展开逐条来源编辑 —— 明细是唯一真源、总数恒等于各条之和；直接在总数框里改会生成一条「手动调整」。
- 暴击区取**期望值** `1 + 暴击率 × 暴伤`。单发伤害是二值的，瑞希一轮循环里伤害次数不多，实战观感与期望可能有出入。
- 队友 buff（七七、迪奥娜等）有触发条件，一律按**全覆盖**处理。
- 部分游戏机制来自社区与解包数据，**非官方文本**，请酌情参考。
